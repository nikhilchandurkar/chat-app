# Production Deployment Guide: Chat App (EC2: 16.113.127.132)

## 1. Single Database Architecture
The production stack uses **exactly ONE database**:
- **Engine**: MySQL 8.0 running inside Docker (`chat_mysql`)
- **Host**: Localhost (`127.0.0.1:3306`)
- **Database**: `chat_db`
- **Volume**: `/opt/chat-app/mysql_data` on host disk

No external databases or multiple databases are required.

---

## 2. Server Configuration Commands

Run the following commands on the EC2 server (`ubuntu@16.113.127.132`):

```bash
# Update and install Nginx
sudo apt-get update
sudo apt-get install -y nginx

# Setup App Directories
sudo mkdir -p /opt/chat-app/{frontend,mysql_data,redis_data,media,logs}
sudo chown -R ubuntu:ubuntu /opt/chat-app
sudo chmod -R 775 /opt/chat-app
sudo chmod -R 777 /opt/chat-app/logs /opt/chat-app/media

# Apply Nginx configuration
sudo cp nginx.conf /etc/nginx/sites-available/chatapp
sudo ln -sf /etc/nginx/sites-available/chatapp /etc/nginx/sites-enabled/chatapp
sudo rm -f /etc/nginx/sites-enabled/default

# Verify and reload Nginx
sudo nginx -t
sudo systemctl restart nginx
```

## 3. GitHub Actions Self-Hosted Runner (Deploy Job)

To allow GitHub Actions to continuously deploy the frontend and backend containers:

```bash
# 1. Stop and remove old runner
cd ~/actions-runner && sudo ./svc.sh stop 2>/dev/null || true
sudo ./svc.sh uninstall 2>/dev/null || true
cd ~ && rm -rf ~/actions-runner

# 2. Download and extract new runner
mkdir ~/actions-runner && cd ~/actions-runner
curl -o actions-runner-linux-x64-2.321.0.tar.gz -L https://github.com/actions/runner/releases/download/v2.321.0/actions-runner-linux-x64-2.321.0.tar.gz
tar xzf actions-runner-linux-x64-2.321.0.tar.gz

# 3. Configure runner (generate token from GitHub Settings -> Actions -> Runners -> New runner)
./config.sh --url https://github.com/nikhilchandurkar/chat-app --token <REGISTRATION_TOKEN> --name ec2-chat-app-runner --labels self-hosted,linux --unattended --replace

# 4. Install and start as systemd service
sudo ./svc.sh install ubuntu
sudo ./svc.sh start
sudo ./svc.sh status
```

## 4. Building the Android APK (Capacitor)

The repository includes native Android project files generated by Capacitor:

1. **Build Web Frontend & Sync**:
   ```powershell
   cd client
   npm run build:ci
   npx cap sync android
   ```

2. **Compile Debug APK**:
   ```powershell
   cd client\android
   .\gradlew.bat assembleDebug
   ```

3. **Output File**:
   `client\android\app\build\outputs\apk\debug\app-debug.apk`
